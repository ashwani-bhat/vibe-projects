🧠 A Photo in a 12KB Neural Net

Don't store the pixels — store a function. A tiny network learns f(x, y) → color until the function is your photo, then the whole image fits in ~12KB of weights. Watch it fight JPEG at the same file size.

Hit ▶ compress and watch a blur become your photo as the network trains (a minute or two is plenty). Then try the 4× render — the net is a continuous function, so unlike pixels it can be sampled at any resolution. Export the weights: that JSON file is the photo.

How it works: this is an implicit neural representation — a SIREN ( Sitzmann et al., 2020). A 2→72→72→3 network with sine activations maps every coordinate to a color; ~5,700 weights quantized to 16 bits ≈ 12KB. Training samples random pixels and runs Adam on the MSE — live, in your browser, via TensorFlow.js. Sine activations (with the w0=30 trick) are what let so small a net capture edges; try the same with ReLU and you get mush. The JPEG panel binary-searches quality until the file matches the network's byte size, so the fight is fair. Your photo never leaves the page.
