🦠 Evolving Walkers

Blobs of springs and joints learn to walk with no brain and no backprop — just mutation, and the brutal rule that whoever crawls furthest gets to reproduce.

The big view replays the current champion in real time — nodes are feet (brighter = grippier), yellow muscles are mid-contraction. Evolution runs in fast-forward behind the scenes: each generation, every creature gets 8 simulated seconds to walk; the far-walking half breeds, the rest are compost. Watch gaits invent themselves around generation 20–50.

How it works: a creature is just nodes and springs. Each muscle rhythmically oscillates its rest length (sine wave with evolved amplitude, period, and phase); each node has an evolved grip that controls how much the ground grabs it. Physics is plain verlet integration with constraint relaxation — ~60 lines, no library. The genome is the body plan plus the rhythm; fitness is distance walked in 8s. Selection is truncation (top half survives), variation is gaussian mutation plus the occasional grown limb, and a trickle of random immigrants keeps the gene pool weird. There is no neural network and no gradient in this project — it's pure evolution, the algorithm that built the things that later built neural networks.
