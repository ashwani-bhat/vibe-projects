trajectory · one ticket, turn by turn

What this is: a simulation of the thing that actually decides whether an agent works — not the model, the harness. A fixed, imperfect model works bug tickets (1–3 real bugs each) through locate → read → edit → test. Every mechanic is a real phenomenon with its real shape: context rot (action accuracy decays as the window fills), quadratic cost (every turn re-reads the whole context), doom loops (identical retries after uninformative errors), compaction risk (a summarizer that drops the one fact you needed), and false success — the worst outcome, a wrong fix that looks done because nothing in the loop could tell. Model competence is a constant in sim.js; only the harness knobs move. With everything on, the same model goes from roughly a third of tickets to over 90%.
